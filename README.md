# CardAssist-AI

Production-ready monorepo for CardAssist-AI.

## Structure
- `frontend`: Web UI application
- `backend`: Core API service
- `agents`: Multi-agent orchestration and specialized AI agents
- `rag`: Retrieval-Augmented Generation subsystem
- `blockchain`: Smart contracts and blockchain integration
- `database`: Database migrations and schema definitions
- `docs`: Documentation
- `tests`: Test suites
- `docker`: Docker configuration files
- `scripts`: Utility scripts
- `.github/workflows`: CI/CD workflows
